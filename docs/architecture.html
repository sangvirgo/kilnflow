② Giải pháp: RAG

Retrieval-Augmented Generation

Thay vì để AI "nhớ mang máng", ta tra cứu dữ liệu thật trước, rồi mới để AI trả lời dựa trên bằng chứng cụ thể.

💡 Giải thích không thuật ngữ

Tưởng tượng bạn đến hiệu thuốc mua thuốc:

  • Cách cũ (LLM): Hỏi bác sĩ — bác sĩ nhớ lại sách giáo khoa, trả lời approximate. Đôi khi sai.
  • Cách RAG: Hỏi bác sĩ → bác sĩ mở hồ sơ bệnh án của bạn → đọc thuốc đang dùng, lịch sử dị ứng → trả lời chính xác dựa trên hồ sơ.

RAG = "mở hồ sơ" cho AI trước khi trả lời.

③ Embedding — Biến chữ thành số

Máy tính hiểu "gần nhau" bằng toán học

Máy tính không đọc được "men xanh ngọc" ≈ "celadon". Nó cần chuyển thành vector số.

🗺️ Giải thích bằng GPS

Giống như GPS: Hà Nội có tọa độ (21.0285, 105.8542), Hải Phòng có tọa độ (20.8449, 106.6882). Khoảng cách giữa 2 điểm = 120km → rất gần.

Tương tự, mỗi mô tả mẻ gốm được chuyển thành vector 768 chiều: 

// Mô tả: "lọ hoa sen 35cm men xanh ngọc"
// → embedding: [0.12, -0.08, 0.45, 0.23, ..., 0.67] // 768 con số

// Mô tả khác: "lo hoa sen 35cm men xanh ngoc" // KHÔNG CÓ DẤU!
// → embedding: [0.11, -0.07, 0.44, 0.22, ..., 0.65] // GẦN GIỐNG HỆT

Dù khác chữ, vector gần nhau → hệ thống biết 2 mô tả này liên quan.

Xem code embedding thật trong Kilnflow
embeddings.core.ts — Gemini Embedding Provider
// Gemini embedding: biến text → vector 768 chiều
export class GeminiEmbeddingProvider implements EmbeddingProvider {
  readonly modelTag = 'gemini-embedding-001';
  readonly dim = 768;

  async embed(texts: string[]): Promise<number[][]> {
    const res = await fetch(geminiEndpoint, {
      method: 'POST',
      body: JSON.stringify({
        requests: texts.map((text) => ({
          model: 'models/gemini-embedding-001',
          content: { parts: [{ text }] },
          outputDimensionality: 768,  // ← 768 chiều
        })),
      }),
    });
    return res.embeddings.map((e) => e.values); // → [[0.12, -0.08, ...], ...]
  }
}

Nếu Gemini API lỗi → tự chuyển sang LocalHashEmbeddingProvider (deterministic, dùng được offline, cùng vector-space).

④ Cosine Similarity — Đo sự "gần"

Hai vector gần nhau = hai ý nghĩa gần nhau

📐 Cosine Similarity

Đo góc θ giữa 2 vector:

cos(θ) = (A · B) / (‖A‖ × ‖B‖)

• cos = 1.0  → giống hệt (góc 0°)
• cos = 0.8  → rất gần (góc 37°)
• cos = 0.5  → có liên quan (góc 60°)
• cos = 0.0  → không liên quan (góc 90°)

🎯 Kết quả thật

Khi hỏi "lọ hoa sen 35cm men xanh ngọc":

Lọ hoa sen 35cm86% giống
Lọ hoa sen 30cm81%
Lọ hoa lá tre 28cm71%

Gemini embedding tìm bằng ngữ nghĩa (không chỉ so chữ cái) → cả "men xanh ngọc" và "celadon" đều match.

Xem code cosine similarity thật
embeddings.core.ts
export function cosineSimilarity(a: number[], b: number[]): number {
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < Math.min(a.length, b.length); i++) {
    dot += a[i] * b[i];   // tích vô hướng
    na  += a[i] * a[i];   // ‖A‖²
    nb  += b[i] * b[i];   // ‖B‖²
  }
  return dot / (Math.sqrt(na) * Math.sqrt(nb)); // → giá trị từ -1 đến 1
}

// Trọng số = sim² → mẻ giống hơn → ảnh hưởng lớn hơn đến kết quả cuối

Chuyển mô tả tự do thành JSON chuẩn 12 trường.

// Output (Zod validated):
{
  "product_name": "lọ hoa",
  "quantity": 200,
  "firing_temp_c": 1280,
  "estimated_clay_kg": 420,  // ← Parser đoán bằng công thức

⚠️ Lưu ý: estimated_clay_kg=420 là SAI — Parser dùng công thức tĩnh, Estimator sẽ sửa ở bước sau.

📦 Estimator Agent (RAG)

Tìm mẻ lịch sử tương tự → tính weighted avg → hiệu chỉnh Parser.

// RAG: top-3 mẻ tương tự nhất
Lọ hoa sen 35cm → sim=0.86 → clay=74kg, hours=14h
Lọ hoa sen 30cm → sim=0.81 → clay=55kg, hours=12h
Lọ hoa lá tre  → sim=0.71 → clay=47kg, hours=12h

// Weighted average (sim²):
clay = (74×0.86² + 55×0.81² + 47×0.71²) / (0.86²+0.81²+0.71²)
     = 60.3 kg  (thay vì 420 kg!)  

// Hiệu chỉnh parsed object:
parsed.estimated_clay_kg = 60.3   // ← RAG sửa Parser
parsed.estimated_firing_hours = 12.8

⑥ Đội hình 5 AI Agents + 1 Monitor

Mỗi agent một nhiệm vụ hẹp — phối hợp thành quy trình

Không có "mega-agent làm tất cả" — mỗi agent có đúng 1 trách nhiệm, tổng hợp bởi Orchestrator.

🔍 Parser

Mô tả tự do → JSON. Few-shot prompt + Zod strict validation. Self-correction loop tối đa 2 lần. Rule dấu tiếng Việt enforced ở prompt.

parser.agent.ts · parser.prompts.ts

📦 Estimator

RAG weighted avg. Embedding 768d → cosine top-3 → sim²-weighted cho clay/hours/6 stages. Cold-start → formula. Cập nhật kho khi batch DONE.

estimator.agent.ts · stage-duration.config.ts

🛡️ Risk/QC

Luật trong code, LLM diễn giải. RulesHint deterministic; prompt bắt buộc tuân theo; fallback mirror exact logic. QC ngưỡng >15% critical.

risk-qc.agent.ts · risk-qc.prompts.ts

🗓 Scheduler

Xếp lò theo ưu tiên/deadline/capacity. LLM đề xuất → sanity-check code → fallback greedy. Zod + capacity validation.

scheduler.agent.ts · greedy.util.ts
